## Описание программы

Эти инструкции помогут вам скачать копию проекта и запустить его на своём локальном компьютере для просмотра, проверки и тестирования[cite: 5, 9].

Мой проект — это **учебное приложение для ведения списка задач и заметок**. Я сделала его во время практической работы по дисциплине **МДК 02.02**, чтобы закрепить навыки работы с Git, разметкой Markdown и оформлением документации[cite: 6, 7, 9].

*Осваивать разметку и репозитории было очень полезно и интересно!* ✨

### Необходимые условия

Что нужно для установки программного обеспечения и запуска проекта на компьютере[cite: 5, 6, 9]:

- **Git** — для скачивания (клонирования) репозитория и управления версиями файлов.
- **Редактор кода** (например, VS Code или Notepad++) — для просмотра и редактирования `README.md` и кода.
- **Веб-браузер** (например, Chrome, Edge или Firefox) — для удобного просмотра.

**Сравнение редакторов для работы с Markdown:**

| Редактор | Платформа | Поддержка Markdown |
| :--- | :---: | :--- |
| VS Code | Windows, Linux, macOS | Встроенная[cite: 9] |
| Notepad++ | Windows | Только с плагинами[cite: 9] |
| Sublime Text | Кроссплатформенный | Встроенная[cite: 9] |
